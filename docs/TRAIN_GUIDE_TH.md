# เริ่มเทรนด้วยปุ่มเดียว

## ก่อนกด Train

เครื่องนี้เตรียม Python, PyTorch XPU, Qwen2-0.5B และ MovieLens-1M ไว้แล้ว
เสียบปลั๊กและเปิดเครื่องไว้ระหว่างรัน

1. ดับเบิลคลิก **START_TRAIN.cmd** ที่หน้าแรกของโปรเจกต์
2. รอข้อความ **พร้อมแล้ว** หน้าต่างจะตรวจไฟล์ ข้อมูล Intel GPU และ Git ให้อัตโนมัติ
3. อ่านค่าที่แสดง แล้วกด **Train** เมื่อต้องการเริ่มจริง

การเปิดหน้าต่างอย่างเดียวยังไม่เริ่มฝึก ไม่มีการติดตั้งหรือดาวน์โหลดเพิ่มจากปุ่ม Train
โค้ดต้องถูก commit และ push จนตรงกับ upstream ก่อน ปุ่มจึงจะพร้อมใช้งาน

## ค่าที่เตรียมไว้

- โมเดลฐาน: Qwen2-0.5B, revision ที่ pin ไว้
- ข้อมูล train / validation / test: 4,096 / 512 / 1,024
- MF embeddings: 64 มิติ
- Batch 4, gradient accumulation 2
- Stage 1 และ Stage 2: 512 optimizer steps ต่อส่วน
- ใช้ Intel Arc 140T ผ่าน XPU; MF ใช้ CPU
- เพดาน 6 ชั่วโมงต่อขั้น ไม่ใช่เวลาที่ต้องรันให้ครบ และไม่ใช่เพดานรวมทั้ง pipeline

ค่าฝึกทั้งหมดอยู่ใน configs/local.yaml โปรแกรมจะเก็บสำเนาค่าที่ใช้จริงให้แต่ละรอบ
ชื่อรอบถูกสร้างให้อัตโนมัติ ผลรอบเก่าไม่ถูกเขียนทับ

## หลังกด Train

โปรแกรมทำตามลำดับ:

1. ฝึก MF และเลือก checkpoint ด้วย validation
2. ฝึก LoRA จากข้อความ เป็น baseline แบบ TALLRec
3. ฝึก MLP เชื่อม MF กับ Qwen เป็น CoLLM-MF
4. ประเมิน test ชุดเดียวกันทั้งสามโมเดล
5. สร้างรายงาน กราฟ CSV และ ZIP อัตโนมัติ

หน้าต่างแสดงขั้นตอนและ log ระหว่างรัน กด **หยุดอย่างปลอดภัย** ได้
ระบบจะรอจบการคำนวณย่อยและเก็บสถานะก่อนหยุด จึงอาจไม่หยุดทันทีในวินาทีที่กด
การปิดฝาเครื่องหรือปิด Windows อาจขัดจังหวะงานได้

ถ้ารอบก่อนหยุด โปรแกรมสามารถนำขั้นที่เสร็จและตรวจสอบแล้วกลับมาใช้ในรอบใหม่
ส่วนขั้นที่ยังไม่เสร็จจะเริ่มขั้นนั้นใหม่ ไม่ใช่การทำต่อจาก optimizer step เดิม
หากโค้ด โมเดล หรือค่าฝึกเปลี่ยนจนเข้ากันไม่ได้ โปรแกรมจะแจ้งให้ตรวจสอบ

## ผลที่ได้

กด **เปิดผลลัพธ์** เพื่อเปิดรายงาน HTML ของรอบนั้น ประกอบด้วย:

- ตาราง AUC ของ MF / TALLRec / CoLLM-MF และส่วนต่างที่วัดได้จริง
- กราฟเปรียบเทียบและกราฟ loss/validation ระหว่างฝึก
- เวลา จำนวน steps ที่ทำจริง และสถานะของแต่ละขั้น
- ลิงก์ predictions.csv, ranking_example.csv, config และรายงานละเอียด
- ZIP ของ source code พร้อมผลการทดลอง โดยไม่รวม weights/dataset/environment

โมเดลที่ฝึกอยู่ใน outputs/<ชื่อรอบ>/ และรายงานอยู่ใน results/<ชื่อรอบ>/
log รวมกับสถานะการรันเก็บใน .cache/jobs/<ชื่อรอบ>/

ถ้าบางขั้นหมดเวลาก่อนครบแผน รายงานจะระบุว่าเป็นผลจากการฝึกไม่ครบแผน
ไม่มีการปรับค่าจาก test scores เพื่อบังคับให้ CoLLM ชนะ baselines
ผลจาก smoke test มีป้ายแยกและใช้เป็นผลวิจัยสำหรับส่งงานไม่ได้
