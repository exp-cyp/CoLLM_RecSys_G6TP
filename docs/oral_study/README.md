# คู่มืออ่านโค้ด CoLLM รายบรรทัด

คู่มือ HTML ภาษาไทยสำหรับทำความเข้าใจโค้ดและเตรียม oral test
เป็นไฟล์เดียวกับคู่มือเดิมที่ใช้ในโปรเจกต์ ครอบคลุม 30 ไฟล์ 5,056 บรรทัด
พร้อมตัวอย่างจริงและคำถามฝึกตอบ 43 ข้อ อ้างอิง source snapshot `c366515`

## เปิดคู่มือ

### ดาวน์โหลดจาก GitHub

1. เปิดไฟล์ [index.html](index.html) ในโฟลเดอร์นี้
2. ดาวน์โหลดไฟล์ `index.html` ลงเครื่อง
3. เปิดไฟล์ที่ดาวน์โหลดด้วย Edge, Chrome หรือ Firefox

หน้าไฟล์ HTML บน GitHub จะแสดง source ของหน้าเว็บ การเปิดไฟล์ที่ดาวน์โหลด
ในเบราว์เซอร์จะแสดงคู่มือพร้อมเมนูเลือกไฟล์และคำอธิบาย
ไม่ต้องติดตั้ง Python หรือดาวน์โหลดโมเดลเพื่ออ่านคู่มือ

### เปิดจาก repository ในเครื่อง

ดับเบิลคลิก `docs/oral_study/index.html` หรือรันจาก root ของโปรเจกต์ใน PowerShell:

```powershell
Start-Process ".\docs\oral_study\index.html"
```

## วิธีอ่าน

1. เริ่มหน้า **ภาพรวม** และ **ตัวอย่างจริง** เพื่อเห็นเส้นทางข้อมูลจนถึงคะแนน
2. เลือกไฟล์จากเมนูด้านบน โดยเริ่ม `configs/local.yaml` → `data.py` → `models.py`
   → `train.py` → `checkpoints.py` → `evaluate.py`
3. อ่าน source ทางซ้ายคู่กับคำอธิบายทางขวาทีละ statement
   expression ที่เขียนหลายบรรทัดมีคำอธิบายร่วมกันพร้อมเลขบรรทัดเริ่มต้น
4. ใช้ช่องค้นหา และตัวเลือกซ่อนคำอธิบายเพื่อลองอธิบายด้วยตัวเอง
5. ใช้คำถาม oral และเฉลยท้ายหน้าภาพรวมตรวจความเข้าใจ

คู่มือเก็บหมายเลขบรรทัดและ anchors เดิม เช่น `#file-1-L54` คือ `data.py` บรรทัด 54
เมื่อเปิดคู่มือในเบราว์เซอร์สามารถใช้ fragment นี้ต่อท้าย URL เพื่อกลับไปยังจุดเดิมได้

HTML มี source และคำอธิบายอยู่ภายในไฟล์ เปิดอ่านแบบ offline ได้
ส่วนนี้เป็นคู่มือศึกษา ไม่มีการเริ่มฝึกโมเดลเมื่อเปิดอ่าน

อ่านคำอธิบายสถาปัตยกรรมแบบย่อได้ที่ [STUDY_GUIDE_TH.md](../STUDY_GUIDE_TH.md)
